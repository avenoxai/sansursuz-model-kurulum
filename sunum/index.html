2omp (Oh My Pi)

Bir YAML dosyası, bir sağlayıcı bloğu

Nerede~/.omp/agent/models.yml JSON da yazabilirsin, JSON geçerli YAML'dır.
providers: refuseless: baseUrl: https://api.refuseless.com/v1 api: openai-completions apiKey: "!security find-generic-password -s sansursuz-refuseless -a $USER -w" models: - id: deepseek-v4.1-flash-abliterated name: DeepSeek V4.1 Flash Abliterated contextWindow: 1048576 maxTokens: 131072 # glm-5.3-flash-abliterated ve glm-5.3-abliterated aynı şekilde venice: # aynı yapı: baseUrl https://api.venice.ai/api/v1, anahtar sansursuz-venice

apiKey üç şekilde yazılır

1. !komut çıktısı anahtar olur. Önerilen.

2. Bir ortam değişkeninin adı.

3. Anahtarın kendisi. Önerilmez.

omp-sansursuz() { command omp --model refuseless/deepseek-v4.1-flash-abliterated \ --approval-mode always-ask "$@" }

always-ask her araç çağrısında onay sorar. Bu modellere bilgisayarına erişim veriyorsun; onayı kapatma.

4OpenCode bonus

Kendi ayarına dokunmadan, ayrı dosya

Nerede~/.config/opencode/opencode.jsonya daayrı dosya + OPENCODE_CONFIG
{ "$schema": "https://opencode.ai/config.json", "provider": { "refuseless": { "npm": "@ai-sdk/openai-compatible", "name": "Refuseless", "options": { "baseURL": "https://api.refuseless.com/v1", "apiKey": "{env:REFUSELESS_API_KEY}" }, "models": { "deepseek-v4.1-flash-abliterated": { "name": "DeepSeek V4.1 Flash Abliterated", "tool_call": true } } } } }

{env:...} anahtarı ortam değişkeninden okur. Değişkeni yalnız OpenCode açılırken ver:

opencode-sansursuz() { OPENCODE_CONFIG="$HOME/.config/sansursuz/opencode.json" \ REFUSELESS_API_KEY="$(security find-generic-password \ -s sansursuz-refuseless -a "$USER" -w)" \ command opencode "$@" }

Venice OpenCode'un hazır kataloğunda zaten var. Refuseless yok, o yüzden elle tanımlanıyor.
